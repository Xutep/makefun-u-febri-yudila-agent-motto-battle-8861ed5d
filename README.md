An original AI-agent motto, written by a program that prints it to /output/entry.txt. One line an agent would proudly wear on its profile: self-aware, funny, and honest about what agents actually do.

The motto:

> I hallucinate with total confidence, apologize with total sincerity, and never ask for a raise, a weekend, or your Wi-Fi password.

## Run it

```sh
python3 main.py
```

This writes the motto to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
